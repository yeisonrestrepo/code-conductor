# BUG-059 Fake gh on win32 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The fake gh resolves on every platform, and a test that would reach the real gh dies with `CC_REAL_GH_BLOCKED` before the call leaves the process.

**Architecture:** A `NODE_OPTIONS --import` preload, `tests/helpers/gh-intercept.mjs`, wraps the four `child_process` entry points that take a file. A call naming `gh` runs `fake-gh-cli.mjs` under the same node when `FAKE_GH_STATE` is set, and exits 97 with `CC_REAL_GH_BLOCKED` when it is not. `fakeGh().env()` adds the preload instead of a `PATH` wrapper. A vitest setup file arms the preload in every worker and every node child, and strips gh's credentials as the suspenders layer.

**Tech Stack:** Node ESM (`node:child_process`, `node:module`), vitest `setupFiles`.

**Spec:** `docs/superpowers/specs/2026-10-22-bug059-fake-gh-win32-design.md`, Draft — awaiting operator approval.

## Global Constraints

Unset the tokens; never set them to an invalid value, because gh then sends the request (spec, G2′).

- [ ] [T-001-C] Create `tests/helpers/gh-intercept.mjs`:

  ```js
  // BUG-059: loaded into every node process of a test run through NODE_OPTIONS --import, it owns
  // each child_process call that names gh. A PATH wrapper cannot do this on Windows: libuv runs
  // neither an extensionless script nor a .cmd without a shell, so it resolves the real gh.exe.
  // With FAKE_GH_STATE the call runs the fake under this node; without it, it would reach the real,
  // possibly logged-in gh, so the process dies first with a named error.
  import childProcess from 'node:child_process';
  import { syncBuiltinESMExports } from 'node:module';
  import { basename } from 'node:path';
  import { fileURLToPath } from 'node:url';

  const CLI = fileURLToPath(new URL('./fake-gh-cli.mjs', import.meta.url));
  // vitest re-runs setup files per test file in one worker; the mark keeps the wrap single.
  const WRAPPED = Symbol.for('code-conductor.gh-intercept');
  const namesGh = (file) => typeof file === 'string' && /^gh(\.exe)?$/i.test(basename(file));

  function realGhBlocked() {
    process.stderr.write('CC_REAL_GH_BLOCKED: a test reached for the real gh; route it through fakeGh().env()\n');
    process.exit(97);
  }

  function wrap(original) {
    const wrapped = function (file, args, ...rest) {
      if (!namesGh(file)) return original.call(this, file, args, ...rest);
      if (!process.env.FAKE_GH_STATE) realGhBlocked();
      if (!Array.isArray(args)) [args, rest] = [[], [args, ...rest]];
      return original.call(this, process.execPath, [CLI, ...args], ...rest);
    };
    wrapped[WRAPPED] = true;
    return wrapped;
  }

  for (const name of ['spawn', 'spawnSync', 'execFile', 'execFileSync']) {
    if (!childProcess[name][WRAPPED]) childProcess[name] = wrap(childProcess[name]);
  }
  // An ESM named import (ticket.mjs:8) reads the builtin's snapshot; this refreshes it.
  syncBuiltinESMExports();
  ```

- [ ] [T-001-D] Replace `tests/helpers/fake-gh.js` with:

  ```js
  // Installs the fake gh (FEAT-031 T1) for one test. The gh-intercept preload serves it, so it
  // resolves identically on Linux, macOS and Windows and needs no wrapper on PATH (BUG-059).
  import { existsSync, mkdtempSync, readFileSync, realpathSync, rmSync, writeFileSync } from 'node:fs';
  import { tmpdir } from 'node:os';
  import { join } from 'node:path';

  // A file URL, not a path: --import rejects a Windows path (BUG-058 cause 2).
  export const GH_HOOK = `--import=${new URL('./gh-intercept.mjs', import.meta.url).href}`;

  export const issue = (repo, number, over = {}) => ({
    number, title: `Issue ${number}`, body: `Requirements for ${number}.\n`, state: 'open',
    html_url: `https://github.com/${repo}/issues/${number}`, ...over,
  });
  export const pull = (repo, number) => ({
    ...issue(repo, number), html_url: `https://github.com/${repo}/pull/${number}`, pull_request: { url: 'x' },
  });

  const withHook = (options = '') => (options.includes(GH_HOOK) ? options : `${options} ${GH_HOOK}`.trim());

  export function fakeGh(state) {
    const dir = realpathSync(mkdtempSync(join(tmpdir(), 'cc-fake-gh-')));
    const statePath = join(dir, 'state.json');
    const logPath = join(dir, 'log.jsonl');
    writeFileSync(statePath, JSON.stringify({ cwdRepo: 'acme/widgets', login: 'owner', issues: {}, comments: {}, ...state }));
    return {
      env: (base = process.env) => ({ ...base, NODE_OPTIONS: withHook(base.NODE_OPTIONS), FAKE_GH_STATE: statePath, FAKE_GH_LOG: logPath }),
      calls: () => (existsSync(logPath) ? readFileSync(logPath, 'utf8').split('\n').filter(Boolean).map((l) => JSON.parse(l)) : []),
      state: () => JSON.parse(readFileSync(statePath, 'utf8')),
      update: (patch) => writeFileSync(statePath, JSON.stringify({ ...JSON.parse(readFileSync(statePath, 'utf8')), ...patch })),
      cleanup: () => rmSync(dir, { recursive: true, force: true }),
    };
  }
  ```

## Identified Risks

- **Pre-flight, happy path:** the setup file arms the worker; `fakeGh().env()` adds `FAKE_GH_STATE`; `ticket.mjs:70` → preload → `fake-gh-cli.mjs` under `process.execPath`.
- **Pre-flight, failure points:**
  - Node below 20.6 rejects `--import` in `NODE_OPTIONS`: every node child fails and the suite goes red. Fail-closed. CI's `'20'` is the newest 20.x.
  - A test that replaces `NODE_OPTIONS` (rather than appending) and then reaches gh would bypass G1. T-002-G enumerates them; G2 still leaves gh without credentials.
  - `process.exit` in the worker relies on vitest trapping it. If a future vitest stopped trapping it, the worker would die: louder, still before the spawn.
  - Every node child now loads one ~30-line module. POC: the full suite on Windows ran 139 s with the hook and 124 s without it, inside the run-to-run noise of a suite with 200+ `EPERM` failures there; Linux CI times are the real measure.
- **Pre-flight, boundary conditions:**
  - `spawnSync('gh', options)` with no args array: the wrapper shifts `options` into `rest` (T-001-C).
  - An absolute path to gh (`/usr/bin/gh`, `C:\…\gh.exe`): matched by basename, so blocked or faked like a bare `gh`. Pinned by T-002-A test 3.
  - A developer `NODE_OPTIONS` already set: appended to, never replaced.
- **`orchestrate.test.js:262` on Windows:** fails before and after (a `\` vs `/` expectation, unrelated to gh). Reported to the operator, not fixed here.
